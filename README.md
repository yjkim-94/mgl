# MGL — My Gay Life

아스텔리아에서 10세부터 20세까지 성장하고, 20세에 반드시 지구로 이동하는 스토리 중심 육성 게임.

## 현재 개발 단계
- **v1.9.3**: Python 게임 엔진 + Vercel Python Functions 리팩토링
- **v1.9.4 (진행 중)**: GitHub 연동 및 Vercel Preview 배포
- 이후: 120개월 플레이 QA → 비주얼 노벨 아트·사운드 → 통합 검증

## 확정된 핵심 규칙
- 10년 / 120개월 플레이
- 월 8 AP, 최대 4회 행동
- 48종 엔딩 및 조건 판정
- 20세 지구 이동 필수
- 튜토리얼 건너뛰기 지원

## 배포 구성
- Python 게임 엔진
- `api/index.py` — Vercel 서버리스 API
- `mgl_serverless.py` — 무상태 요청 처리
- `web/` — 프런트엔드
- `vercel.json` — 라우팅

> **주의:** 이 저장소는 현재 초기 설정 단계입니다. 전체 v1.9.3 소스가 아직 업로드되지 않았으므로 배포 준비 완료 상태가 아닙니다.
