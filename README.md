# MGL v1.3 — 진로 탐색 가이드 및 NPC 분기 서사

> Python 3.10+ · 별도 Python 패키지 설치 불필요 · 로컬 웹 게임 · 육성 120개월

## 시작하기

```bash
cd mgl_v13
python mgl_web.py --no-browser
```

브라우저에서 `http://127.0.0.1:8765`로 접속합니다. `--no-browser`를 생략하면 시스템 브라우저를 열도록 시도합니다. 서버를 끝내려면 Ctrl+C를 누릅니다.

게임 화면에서는 **목표 엔딩 선택 → 진로 준비 지도 확인 → 월별 행동/생활 이벤트/인물 서사 선택 → 다음 달** 순서로 플레이합니다. 한 달 최대 8 AP, 4회 활동. 20세가 되면 반드시 지구로 이동하며 아스텔리아의 NPC가 자동으로 지구에 동행하지 않습니다. 성적 콘텐츠나 미성년자 클럽 이벤트는 포함하지 않습니다.

## v1.3 새 기능

- **진로 준비 지도**: 필수 능력치, 교육, 프로젝트, 연계 이벤트, 누적 취미, 가치관, 관계, 자율성, EAR, 연령 기한을 실제 현재 상태에 근거해 표시합니다. 전문화·기한 경고도 제공합니다.
- **힌트 수준**: 끄기 / 간단히 / 자세히. 선택은 저장 파일에도 보존됩니다. 힌트는 자동 행동이 아니며, 사용자가 행동을 누르기 전까지 자원을 쓰지 않습니다.
- **6명의 분기 서사**: 리안·에드윈·시온·이든·카일·노아. 각 5개 노드(공통 도입 1 + 협력/자립 중간 2 + 협력/자립 결말 2), 총 30개 서사 노드, 60개 선택지를 추가했습니다. 경로당 3개의 에피소드를 경험합니다.
- **연령 제한**: 서사 도입 12~14세, 전개 15~17세, 결말 18~19세. 필요한 선행 선택과 관계 수치를 모두 충족해야 진행합니다.
- **원래 생활 이벤트 호환**: 기존 이벤트 38종을 그대로 사용합니다. 신규 서사는 별도 표시 슬롯을 써서 원래 필수 이벤트 3개가 가려지지 않습니다.
- **저장 호환성**: v1.2 `save_schema=1` 형식을 그대로 읽고, `hint_mode` 키만 선택적으로 추가합니다. 기존 저장 파일은 `detailed` 힌트로 복원됩니다.

## 검증 재현

```bash
python -m unittest discover -s tests -v
python mgl_v13_validate.py --balance-runs 12
```

`mgl_v13_validate.py`는 48개 분기 경로(6 NPC × 2 경로 × 2 중간 선택 × 2 결말 선택), 48종 과거 엔딩 성공 경로, 5개 힌트 비중 × 12개 시드의 120개월 시뮬레이션을 검증하고 CSV를 갱신합니다. 고정 시드 `20261029`를 사용합니다. **실제 이용자 관찰이 아니라 결정론적 합성 행동 정책**입니다. `--balance-runs`를 올리면 여러 목표로 확장할 수 있으나 시간이 증가합니다.

### 주요 API

- `GET /api/state`: 진로 지도(`career_roadmap`), 서사 상태(`stories`), 상태 정보
- `GET /api/actions`: 실행 가능한 행동 목록. `group=story`인 항목은 서사
- `POST /api/hint`: `{"mode":"off|light|detailed"}`
- `POST /api/action`: 예시 `{"kind":"life","args":{"id":"ST_RIAN_1_START","choice":"together"}}`
- `POST /api/advance`: 다음 달 진행
- `POST /api/save`, `POST /api/load`: 저장 슬롯 조작

안전을 위해 웹 서버는 로컬 호스트(`127.0.0.1`)에만 바인딩됩니다. 다른 PC 또는 공용 인터넷에 공개할 용도의 인증/보안 설계는 아닙니다.

## 미완료 및 향후 작업

실제 브라우저 시각 회귀 테스트는 실행 환경의 로컬 네트워크 브라우저 접근 제한 때문에 완료되지 않았습니다. API 통합 테스트와 JS 문법 검사만 실행되었습니다. 스토리의 서술/대사 품질, 실제 이용자의 전략 발견률, 모든 직업 간 상대 난이도는 별도 플레이 테스트가 필요합니다. 48종 엔딩의 유효한 경로가 있다는 사실은 일반 플레이어가 모두 쉽게 달성한다는 의미가 아닙니다.
