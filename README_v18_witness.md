# MGL v1.8: 120개월 엔딩 성공 경로 탐색

실행: `python mgl_v18_witness_search.py --attempts 2`

- 기존 미달성 22종 × 2개 결정적 시드/정책 = 44회 실제 120개월 실행.
- 목표 엔딩 조건 충족: 44/44회, 엔딩 종류 22/22종.
- 모든 실행에서 20세 지구 이동 정확히 1회.
- 568건은 `act()`의 `score_failed` 반환 횟수이며, 규칙 위반 거부 건수와 구분해야 함. 재시도 가능한 실패가 포함될 수 있음.
- 기존 엔딩 해금 조건은 수정하지 않음.
- 이번 검증은 조건 충족(eligible)을 확인하며 최종 선택(selected) 여부는 별도로 검증해야 함.
- 성공 경로를 찾았다고 추천 UI의 모든 정책에서 같은 성공률을 보장하는 것은 아님.
- 결과: `mgl_v18_witness_trials.csv`, `mgl_v18_witness_summary.json`.
